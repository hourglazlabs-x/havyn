# HAVYN vault drive kit

Fills a USB drive with the family's offline library. Generated by `tools/build.py` from the archive catalog in `src/content.js`; don't edit these files by hand.

| | |
|---|---|
| **Drive** | 1–2 TB USB SSD, formatted **exFAT** (Macs, PCs and iPhones read it; files over 4 GB fit) |
| **Core set** | about 163 GB: the phone set, Wikipedia with pictures, medical references, skills and repair, video, offline AI, software |
| **Everything** | about 424 GB (`--full` / `-Full`) |

**Mac or Linux** (Terminal):

```
curl -fsSL https://raw.githubusercontent.com/hourglazlabs-x/havyn/main/vault/get-vault.sh | bash -s -- /Volumes/HAVYN-VAULT
```

**Windows** (PowerShell; change `E:` to the drive's letter):

```
irm https://raw.githubusercontent.com/hourglazlabs-x/havyn/main/vault/get-vault.ps1 -OutFile get-vault.ps1; powershell -ExecutionPolicy Bypass -File .\get-vault.ps1 -Drive E:\
```

What it does: finds the newest copy of each archive in the Kiwix library, downloads with resume, verifies each archive against the
SHA-256 that Kiwix publishes, removes older copies of the same archive, fetches the newest software releases, and writes
`START-HERE.html` on the drive. Re-run the same command to finish, retry or update. `--list` / `-List` shows the plan without
downloading. `HAVYN_ONLY=p-wikimed,d-ifixit` fetches just those catalog items.

Sizes are from the Kiwix mirror listings on 2026-11-14; items marked `~` in the app are estimates.
